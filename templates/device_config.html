اطلاعات اتصال به سرور
آدرسی که ESP32 برای ارسال داده باید به آن درخواست POST بزند.
این کد را در فایل config.py دستگاه قرار دهید.
نکته امنیتی: این کد یکتا منحصر به فرد است. آن را با کسی به اشتراک نگذارید.
تنظیمات GPRS (SIM800C)
پارامترمقدار پیش‌فرضتوضیحات
APNmtnirancellمتناسب با اپراتور خود تغییر دهید
Usernameدر صورت نیاز
Passwordدر صورت نیاز
برای اپراتور ایرانسل: APN=mtnirancell
برای اپراتور همراه اول: APN=mcinet
برای اپراتور رایتل: APN=raytel
کد نمونه MicroPython

فایل config.py را روی ESP32 با مقادیر زیر تنظیم کنید:

# config.py - تنظیمات دستگاه ESP32

import network
import time

# ========== تنظیمات سرور ==========
SERVER_URL = "{{ api_url }}"
DEVICE_CODE = "{{ device_code }}"

# ========== تنظیمات سنسورها ==========
# AHT20 (دما و رطوبت)
AHT20_SDA = 2
AHT20_SCL = 1

# سنسور رطوبت خاک (خازنی)
SOIL_SENSOR_ADC = 4

# HC-SR04 (سنسور فاصله تانک)
HC_SR04_TRIG = 5
HC_SR04_ECHO = 6

# ========== تنظیمات GPRS (SIM800C) ==========
APN = "mtnirancell"
GPRS_USER = ""
GPRS_PASSWORD = ""

# ========== تنظیمات رله‌ها ==========
# لیست GPIO رله‌ها (از سرور دریافت می‌شود)
RELAY_GPIO_LIST = [12, 13, 14, 15]

# ========== تنظیمات دستگاه ==========
SEND_INTERVAL = 60  # ثانیه
HTTP_TIMEOUT = 30   # ثانیه
دانلود فایل‌های نمونه MicroPython
مراحل راه‌اندازی دستگاه:
  1. فایل config.py را با مقادیر بالا تنظیم کنید
  2. فایل‌های main.py, sensors.py, sim800.py, relay.py را روی ESP32 کپی کنید
  3. دستگاه را راه‌اندازی مجدد کنید
  4. در این صفحه وضعیت اتصال را بررسی کنید
